## 二、核心修改点

### 1) 页面改为 “div 片段” 结构

**目的**：自定义 HTML 只保留 `div`，不包含 `DOCTYPE/html/head/body`。

**做法**：
- 删除：`<!DOCTYPE ...>`, `<html>`, `<head>`, `<body>` 等外壳
- 用一个外层 `div` 包住全部内容

**已使用的外层 `div` id**：
- `AI平台.html` → `#ai-platform-custom`
- `AI三维.html` → `#ai-3d-custom`
- `网站开发.html` → `#web-dev-custom`
- `程序开发.html` → `#program-dev-custom`
- `APP开发.html` → `#app-dev-custom`
- `联系我们.html` → `#contact-custom`
- `人才招聘.html` → `#recruitment-custom`

**结构示例**：
```
<div id="xxx-custom">
  <!-- 外链 CSS -->
  <!-- 原页面内容 + 脚本 -->
</div>
```

---

### 2) 只保留 div 内的外链加载

**目的**：所有 CSS/JS 外链都放到 div 内，方便直接粘贴到自定义 HTML。

**做法**：
- 把 `<link>`、`<script>` 都保留在 `div` 内
- 确保 `div` 之外没有外链资源

---

### 3) 去掉头部与尾部模块（仅原页面存在时）

**头部特征**：
- `full_column` + `new_navigation`
- 通常包含导航背景图和菜单 HTML

**尾部特征**：
- `site_footer` / `footer_content`
- 或包含 `inbuttom='1'` 以及“版权所有/备案号”

**已处理页面**：
- `AI平台.html`（头部删除）
- `APP开发.html`（头部删除、尾部删除）
- `程序开发.html`（头部删除、尾部删除）
- `网站开发.html`（头部删除、尾部删除）

`AI三维.html`、`联系我们.html` 本身没有这些结构，因此无需删除。

### 3) 底部空白问题（已修复）

**问题描述**：
页面底部出现明显空白区域。

**根本原因**：
- `#canvas` 原始高度写死为 `5866px`
- 之前的 `fixCanvasHeight` 脚本只取最后一个文字元素计算高度（top:5674 + height:55 = 5729px）
- 但 Swiper 轮播的实际底部在 5866px（top:5066 + height:800）
- 两者差值 137px + margin-top 偏移配合问题，导致底部出现空白

**修复方案**：

a) 去掉 `#canvas` 的固定 `height:5866px`，改为不设高度由脚本动态控制

```html
<!-- 修改前 -->
<div id="canvas" style="margin: -867px auto 0;width:1500px;height:5866px;">

<!-- 修改后 -->
<div id="canvas" style="margin: -867px auto 0;width:1500px;">
```

b) 替换底部的 `fixCanvasHeight` 脚本，改为遍历所有子元素取最大底部值：

```javascript
function fixCanvasHeight(){
    var canvas = $('#canvas');
    if(!canvas.length) return;
    var maxBottom = 0;
    canvas.children('.cstlayer, .full_column').each(function(){
        var $el = $(this);
        if($el.css('display') === 'none') return;
        var t = parseInt($el.css('top')) || 0;
        var h = $el.outerHeight(true) || 0;
        var bottom = t + h;
        if(bottom > maxBottom) maxBottom = bottom;
    });
    if(maxBottom > 0){
        canvas.css('height', maxBottom + 'px');
        $('#scroll_container_bg').css('height', (maxBottom - 867) + 'px');
    }
}
```

**修复效果**：
- 画布高度精确匹配实际内容底部，无多余空白
- 后续增删内容时高度自动适配，无需手动调整
