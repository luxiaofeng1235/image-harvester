# 采集 + 入库（zgzonre 产品）开发文档（更新版）

> 当前流程：**先采集分类 goods_id → 存 zgz_products_cate → 再按 goods_id 抓详情并写入 zgz_products**。

---

## 1. 核心数据字段

### 1.1 分类 goods_id 表（zgz_products_cate）

- `category_path`：分类标识（如：`加热器->导热油加热器`）
- `goods_id`：商品ID（product_id）
- `source_url`：详情页 URL

### 1.2 商品详情表（zgz_products）

- `product_id`：商品ID（product_id）
- `title`：商品名
- `images`：图片列表（原始URL），多图用 `|` 分隔
- `oss_image_url`：OSS图片列表（上传后的URL），多图用 `|` 分隔
- `content_html`：详情 HTML
- `category_path`：分类标识 对应zgz_products_cate.category_path
- `source_url`：详情页 URL 对应zgz_products_cate.source_url

---

## 2. 表结构

### 2.1 zgz_products_cate（分类商品ID表）

```sql
CREATE TABLE `zgz_products_cate`
(
    `id`            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '自增主键',
    `category_path` VARCHAR(255) NOT NULL COMMENT '分类标识，如 加热器->导热油加热器',
    `goods_id`      VARCHAR(64)  NOT NULL COMMENT '商品ID(product_id)',
    `source_url`    VARCHAR(512) NOT NULL COMMENT '详情页 URL',
    `created_at`    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uniq_category_goods` (`category_path`,`goods_id`),
    KEY             `idx_category` (`category_path`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='zgzonre 分类商品ID表';
```

### 2.2 zgz_products（商品详情表）

```sql
CREATE TABLE `zgz_products`
(
    `id`            BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '自增主键',
    `product_id`    VARCHAR(64)  NOT NULL COMMENT '源站 product_id',
    `title`         VARCHAR(255) NOT NULL COMMENT '商品名',
    `images`        TEXT         NOT NULL COMMENT '原始图片列表，| 分隔',
    `oss_image_url` TEXT         NULL COMMENT 'OSS图片列表，| 分隔',
    `content_html`  MEDIUMTEXT   NOT NULL COMMENT '详情 HTML',
    `category_path` VARCHAR(255) NOT NULL COMMENT '分类标识，如 加热器->导热油加热器',
    `source_url`    VARCHAR(512) NOT NULL COMMENT '详情页源URL',
    `created_at`    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at`    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uniq_product` (`product_id`),
    KEY             `idx_category` (`category_path`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='zgzonre 产品采集表';
```

## 3. 最新采集流程（单阶段）

### 3.1 从表读取 goods_id

> 分类标识不再人工输入，直接从 `zgz_products_cate.category_path` 读取。

1) 直接从 `zgz_products_cate` 读取 goods_id 列表
2) 根据 category_path 分批抓取（可控）

示例 SQL：

```sql
SELECT goods_id, source_url, category_path
FROM zgz_products_cate
WHERE category_path = '加热器->导热油加热器';
```

### 3.2 逐条抓详情并入库

1) 请求详情页 URL
2) 提取 `title / images / content_html`
3) 写入 `zgz_products`

## 4. 数据自检流程（必须）

### 4.1 分类 goods_id 数量核对

- 采集时统计列表页商品总数
- 采集后查询数据库数量

示例：

```sql
SELECT COUNT(*) AS total
FROM zgz_products_cate
WHERE category_path = '加热器->导热油加热器';
```

结果应与分类页商品数量一致。

### 4.2 商品详情数量核对

```sql
SELECT COUNT(*) AS total
FROM zgz_products
WHERE category_path = '加热器->导热油加热器';
```

应与 `zgz_products_cate` 对应数量一致（除非有详情抓取失败）。

## 8. 请求 Header 说明（必须）

该站点无 UA/Referer 时容易 403，抓取时必须带基础 Header：

```python
headers = {
  "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0 Safari/537.36",
  "Referer": "https://www.zgzonre.com/"
}
```

如遇异常，可再补 `Accept` / `Accept-Language` 或 Cookie。


## 9. 图片清洗规则（必须）

- 图片必须保留 **HTTPS** 完整地址，例如：
  - `https://pro23233665-pic5.ysjianzhan.cn/upload/H_1.jpg`
- 多张图片使用 `|` 连接：
  _- `url1|url2|url3`_


## 10. 详情 HTML 提取规则

- 详情内容优先从以下容器提取（任选其一存在即可）：
  1) `.artview_detail`
  2) `.goods-info`
  3) `.desckey0`

- 提取 `innerHTML` 原样入库（不转纯文本）。


## 11. 图片提取规则

优先从产品详情图区域提取：

1) **主图**：`.wp-tb_product_detail-imgpreview` 的 `src`
2) **缩略图列表**：`.wp-new-prodcuts-detail-picture-small-element img` 的 `src`

规则：
- 若缩略图存在，使用缩略图列表作为最终图片集
- 若缩略图不存在，使用主图作为图片集
- 去重后用 `|` 拼接
- 保留 HTTPS 完整地址

### 13.4 导入逻辑说明

1. 从 Excel 读取商品数据
2. 下载原始图片并上传到 OSS（带 Header/UA 防 403）
3. 通过 `product_id` 判断是否存在：
   - 存在则更新（Update）
   - 不存在则插入（Insert）
4. `source_url` 字段留空（Excel 数据无此字段）
5. 完成后自动执行数据自检，核对 Excel 与数据库数量
