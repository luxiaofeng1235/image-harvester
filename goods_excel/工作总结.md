# 网易严选商品数据采集工作总结

## 完成内容

### 1. 搜索接口调通
- 确认网易严选搜索接口 `xhr/search/search.json`，只需 `keyword`、`page`、`size`、`__timestamp` 参数
- 详情数据通过 HTML 页面中的 `JSON_DATA_FROMFTL` 变量提取（服务端渲染，非 API）

### 2. 数据提取逻辑
对齐 `NetEaseDataExtractor.php` 的解析逻辑：
- 引号感知的括号匹配提取 JSON 字符串
- 单引号值/属性名替换为双引号修复非标准 JSON
- SKU 价格收集（skuList / skuMap 两种结构）
- 详情 HTML 拼接（attrList 属性 + detailHtml 补充）

### 3. 采集脚本 `fetch_details.py`
一键采集工具，输入关键词自动完成：搜索 → 抓详情 → 导出 Excel
```bash
python3 fetch_details.py 非遗 --size 50
python3 fetch_details.py 茶具 --size 20
```

### 4.1 江苏本地化约束（AI生成阶段）
- 所有分类商品默认带“江苏相关”语义，不生成泛化全国话术
- 标题/副标题优先体现：江苏、苏式、盐城、本地产业、地方文化
- 禁止输出外链、联系方式、医疗功效等违规内容
- 价格必须为数字，且区间合理（可按分类配置）

### 4.2 AI提示词建议（用于 `.env`）
```text
你是资深电商商品策划与文案助手。请根据输入的分类和关键词，生成“江苏相关”可上架商品数据。字段包括title、subtitle、price、selling_points、attrs。要求中文自然、避免夸张与违规词、不得输出链接、不得重复、价格必须是合理数字。仅返回JSON数组，不要输出额外说明。
```
