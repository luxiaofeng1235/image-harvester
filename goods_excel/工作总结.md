# 网易严选商品数据采集工作总结

## 完成内容

### 1. 搜索接口调通
- 确认网易严选搜索接口 `xhr/search/search.json`，只需 `keyword`、`page`、`size`、`__timestamp` 参数
- 详情数据通过 HTML 页面中的 `JSON_DATA_FROMFTL` 变量提取（服务端渲染，非 API）

### 2. 数据提取逻辑
对齐 `NetEaseDataExtractor.php` 的解析逻辑：
- 引号感知的括号匹配提取 JSON 字符串
- 单引号值/属性名替换为双引号修复非标准 JSON
- SKU 价格收集（skuList / skuMap 两种结构）
- 详情 HTML 拼接（attrList 属性 + detailHtml 补充）

### 3. 采集脚本 `fetch_details.py`
一键采集工具，输入关键词自动完成：搜索 → 抓详情 → 导出 Excel
```bash
python3 fetch_details.py 非遗 --size 50
python3 fetch_details.py 茶具 --size 20
```

### 4.1 江苏本地化约束（AI生成阶段）
- 所有分类商品默认带“江苏相关”语义，不生成泛化全国话术
- 标题/副标题优先体现：江苏、苏式、盐城、本地产业、地方文化
- 禁止输出外链、联系方式、医疗功效等违规内容
- 价格必须为数字，且区间合理（可按分类配置）

### 4.2 13市覆盖与多维度生成约束（新增）
- 地域覆盖按江苏13市轮转/均衡：南京、无锡、徐州、常州、苏州、南通、连云港、淮安、盐城、扬州、镇江、泰州、宿迁
- 不允许长期集中在少数城市（如仅南京、南通）；单批次数据需尽量覆盖更多城市
- 生成维度不能只写“纪念品”，应同时覆盖以下维度（按分类组合）：
  - 城市/地域维度：13市地标、地方文化、地理标识
  - 品类维度：特产礼盒、文创纪念、非遗手作、AI科技周边、赛事周边
  - 场景维度：商务送礼、节日礼赠、企业团购、文旅伴手礼、个人收藏
  - 人群维度：游客、球迷、企业客户、年轻用户、家庭用户
  - 价格带维度：低价引流、中端主销、高端礼赠
- 标题与副标题需要体现“城市 + 品类 + 场景/卖点”，减少同质化文案

### 4.7 工程化 Prompt 组装方案（按分类个性化）
- 目标：同一套生成程序，按 `category_id` 自动注入不同约束，产出稳定可控的数据
- 推荐组装结构：
  - `system_prompt`：全局身份与总规则（江苏本地化、合规、仅返回JSON）
  - `category_profile`：分类专属规则（价带、风格、禁区、示例）
  - `task_prompt`：本次任务参数（关键词、生成条数、城市覆盖）
  - `output_schema`：固定字段与类型约束（title/subtitle/price/selling_points/attrs）
  - `self_check_prompt`：模型自检要求（去重、价格合法、城市覆盖）

### 4.8 图片采集与落库方案（开发标准）

#### 4.8.1 图片来源接口
- 接口：`https://ptapi.jsss999.com/api/fetch/getImages?key=<关键词>`
- 返回结构：`{"code":1,"msg":"获取成功","data":[url1,url2,...]}`
- 使用方式：按商品关键词请求；关键词可由“分类词 + 城市词 + 品类词”拼接

#### 4.8.2 映射规则（核心）
- `data[0]` 作为主图，写入 `jj_wangyi_goods.image`
- `data[1..n]` 作为详情图，拼接到 `description` 的 HTML 中
- 详情图拼接格式建议：
```html
<div class="product-description">
  <p><strong>核心卖点</strong>：{{selling_point}}</p>
</div>
<div class="product-detail">
  <p><img src="详情图URL1" /></p>
  <p><img src="详情图URL2" /></p>
</div>
```

#### 4.8.3 质量与容错规则
- 至少需要 1 张可用图；若不足 1 张则该条重试或跳过
- 建议每条商品详情图数量：`3 ~ 8` 张，避免过少或过长
- 图片 URL 去重（同商品内不重复）
- 下载校验建议：
  - HTTP 状态码为 200
  - 内容长度 > 1KB
  - Content-Type 为图片类型（jpg/png/webp/gif）
- 接口异常重试：最多 3 次（指数退避：1s/2s/4s）

#### 4.8.4 分类差异化建议
- `126 江苏特产`：优先食品实拍、礼盒图、地方元素图
- `127 非遗`：优先工艺细节图、材质图、器型图
- `128 AI科技`：优先方案示意图、系统界面图、交付场景图
- `129 苏超纪念品`：优先周边实物图、应援场景图、城市元素图
